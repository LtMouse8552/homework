| 文件 | 说明 |

## 📊 扫描结果概览

依赖许可证分布（按数量）：

- MIT ×227（占比最高）
- ISC ×44
- BSD-3-Clause ×10
- Apache-2.0 ×8
- BlueOak-1.0.0 ×8
- BSD-2-Clause ×7
- 其余为 CC-BY-3.0、CC0-1.0、WTFPL、0BSD、Python-2.0 等少量宽松许可证

扫描到的依赖均为主流宽松许可证（Permissive），未发现 Copyleft 强约束（如 GPL、AGPL）类许可证，整体合规风险较低。

## 🛠 方法说明

使用许可证扫描工具对项目依赖清单进行批量检测，输出 CSV / JSON 明细与统计摘要，再结合各许可证条款完成合规性分析，最终整理为课程报告。
